# Animal Classification Project - Brief Description

## What is this project?

A **real-time animal classification web application** that uses deep learning to identify different animal species from images or live webcam feeds. Built with TensorFlow and Streamlit, this project demonstrates end-to-end machine learning implementation from model training to deployment.

## Key Highlights

- 🎯 **Real-time Classification**: Classify animals instantly using webcam or uploaded images
- 🧠 **Deep Learning**: Uses transfer learning with MobileNetV2 (pre-trained on ImageNet)
- 🌐 **Web Interface**: User-friendly Streamlit app with intuitive UI
- 📊 **Detailed Results**: Shows top-3 predictions with confidence scores
- ⚡ **Optimized**: Lightweight model (~11MB) for fast inference

## Technology Stack

- **Python** + **TensorFlow/Keras** for deep learning
- **MobileNetV2** for transfer learning
- **Streamlit** for web interface
- **OpenCV** for image processing

## Use Cases

- Educational tool for learning about animals
- Wildlife identification applications
- Animal classification demos
- Learning ML/deep learning concepts

## Quick Start

1. Install dependencies: `pip install -r requirements.txt`
2. Train model (or use pre-trained): `python train_model.py/train.py`
3. Run app: `streamlit run app.py`
4. Open browser and classify animals!
